# VinciSub · 奇奇字幕

达芬奇原生 Python 脚本，用 Qwen3-ASR 在本机识别中文并生成 SRT。所有操作在达芬奇的脚本窗口中完成，无网页界面或本地 HTTP 服务。

## 当前 MVP

1. 在达芬奇打开时间线，需要局部识别时按 I / O 设置入点、出点；未设置时使用整条时间线。
2. 打开 **工作区 → 脚本 → Utility → VinciSub**，在音轨列表勾选一条或多条音轨；不勾选时自动识别所有可听音轨。
3. 可点击右上角「词库设置…」，在二级窗口输入人名、品牌或专业词（每行一个或逗号分隔），勾选「启用词库」并点击「保存」。确认窗口显示的范围，点击「生成字幕」。无需导出音频、选择文件或设置保存路径。
4. 识别完成后通过 Resolve API 写入原始时间线，并校验全部字幕位置。再次生成时，读取已有 VinciSub 字幕轨的当前内容，优先检查启用轨道；找到与选区无重叠的轨道就复用，全部冲突或锁定才新建。窗口保持显示，无菜单点击或检查器操作。
5. 点击「读取全部字幕」可加载当前时间线所有字幕轨的现有字幕，包括历史生成、手动添加和未启用轨道；列表按时间排序并显示 ST 轨号，不受入出点限制。
6. 双击列表里的字幕，在独立编辑窗口修改文字及开始/结束时间，再点击「保存并同步」。修改会更新字幕所属的原字幕轨，不再新建轨道；「写入字幕轨」也可用于重试同步。

**接入验证状态：**macOS / Resolve Studio 21.1 / 25fps 中文界面已通过原生生成 → 本地识别 → 原时间线字幕轨的完整实测，以及已有字幕保留和重复写入防护测试。

音频直接从所选音轨对应的源素材解码到内存，不调用 Resolve 渲染、不创建导出音频文件。保留片段裁剪、空隙和时间线位置；字幕时间以整条时间线起点为零，包括时间线从 01:00:00:00 开始的情况。

入出点优先读取音频范围，其次视频范围；只有单侧标记时，另一侧使用时间线边界。窗口自动更新范围，新增或重命名轨道后点击「刷新时间线 / 音轨」。自动模式下，有 Solo 时只识别未静音的 Solo 轨道，否则识别全部未静音音轨；支持多条 Solo。点击生成时读取最新状态，全部静音时明确提示。禁用片段和断开的音频通道会跳过；显式选中的轨道即使在混音中静音也可识别。

## 安装（macOS）

已实测：Apple Silicon、DaVinci Resolve Studio 21.1、Python 3.12、Qwen3-ASR-0.6B + Qwen3-ForcedAligner-0.6B，使用 MPS 推理。其他版本及 1.7B 模型尚未实测。

从 [GitHub Releases](https://github.com/Chokamin/VinciSub/releases) 下载源码包并解压，或运行 `git clone https://github.com/Chokamin/VinciSub.git`。

安装 [uv](https://docs.astral.sh/uv/getting-started/installation/) 和 FFmpeg（`brew install ffmpeg`），然后在项目目录执行：

```sh
bash scripts/setup.sh
bash scripts/install-resolve.sh
```

自动落轨直接调用 Resolve API，不需要 Swift、辅助功能或 System Events 自动化授权。旧版 VinciSub Helper 已不再使用。

重启达芬奇后从脚本菜单打开。需要 Studio 版的 UIManager，并将偏好设置 → 系统 → 常规 → 外部脚本设为「本地」。脚本入口链接到项目目录，移动目录后需重新安装入口；安装程序不会覆盖已有同名入口。

默认使用 0.6B 模型，首次运行会从 Hugging Face 下载识别和时间对齐模型，需网络及数 GB 空间；之后完整缓存可离线使用。音频留在本机，不上传识别服务。模型许可证见 [Qwen3-ASR 官方仓库](https://github.com/QwenLM/Qwen3-ASR)。

## 模型管理与下载

点击主面板「模型管理…」打开独立窗口，选择 Qwen3-ASR 0.6B、1.7B 或共用时间对齐模型，查看下载状态、实际本地占用大小和完整保存路径。路径旁的「在 Finder 中打开」可直接打开所选模型文件夹；尚未下载时打开下载目录。支持「下载 / 补全」「取消下载」及「删除本地模型」；删除按钮再次确认后执行。识别或下载期间禁止删除，避免破坏正在使用的文件。

首次生成会自动下载所需模型。下载开始后自动弹出独立原生窗口，显示包裹图标、动态圆点、真实字节进度条、百分比和已下载/总大小；可选择「后台下载」或「取消下载」；查询文件信息时显示等待动画，不编造百分比。取消后保留部分下载，重试交由下载器续传。模型下载完整后进入加载、识别阶段，下载窗口自动关闭。

模型统一保存在 `.vincisub/models/hub/`；大小按实际缓存文件统计，不重复计入快照符号链接。删除共用时间对齐模型后，两种识别模型下次生成都需重新下载该依赖。删除只操作所选模型，不影响词库、字幕或另一个模型。

## 词库

主面板只保留「词库设置…」入口。设置窗口中点击「保存」后生效；「取消」或关闭设置窗口放弃本次编辑，重新打开读取已保存内容。

词库保存在本机 `.vincisub/vocabulary.json`，在本工具各时间线之间共用。取消「启用词库」可临时停用而不删除词条，清空输入后保存可清空词库。最多 100 个词、合计 2000 字，每词最多 64 字；建议只保留当前素材相关的少量专名。每次生成保存独立词库快照，运行中的任务不会受后续修改影响。

词库通过 Qwen3-ASR 的 `context` 参数提示模型，不是强制替换，也不是训练模型。它可能改善专名识别，但不保证命中或整体准确率提升，过多无关词汇可能干扰结果；仍需校对。

## 限制与数据

- 自动 Solo / Mute 模式目前仅验证 Resolve 21.1：Mute 通过接口读取，Solo 通过临时时间线元数据读取；元数据用后删除，不导出音频。无法读取时明确报错，不回退识别全部轨道。其他版本暂用手动勾选音轨模式；总线 Solo / Mute 和 Solo Safe 等高级路由未验证。
- 单次选定范围最长 30 分钟；长音频按低能量位置分块，边界附近仍可能出现错字或漏字。
- 简体转换、标点恢复、优先按标点和停顿断句，字数作为上限；不支持说话人分离、翻译、字幕样式或实时识别。识别后仍需校对。
- 识别源音频，不复现 Fairlight 的降噪、增益自动化、音效或总线混音。变速片段按首尾时间映射并提示校对，速度曲线中的局部时序可能存在偏差；倒放、嵌套/复合片段及外部同步音频映射暂不支持，会明确报错。
- 初次写入新建字幕轨；后续无重叠选区复用已有 VinciSub 轨道，合并旧字幕并刷新片段，保留旧文字、时间及其他轨道。校对只更新当前任务所属字幕。单条字幕样式会随片段重建，请在校对完成后设置；轨道样式不主动更改。
- 同步前核对全部字幕 ID、文字和时间；校对同步遇到外部修改仍拒绝覆盖；新选区生成则读取并保留轨道当前文字和时间，不因旧片段 ID 变化而跳过。手动改名且无法对应历史记录的轨道不自动复用。失败时尝试恢复原字幕内容，恢复失败会提示检查任务目录的 `edit-backup.json`。
- 自动落轨目前限制 macOS / Resolve 21.1 / 整数帧率 24、25、30、48、50、60；实际写入仅验证 25fps；其他帧率待实测，写入不依赖界面语言。掉帧及分数帧率明确拒绝。长字幕任务尚未实测。
- 「保存 SRT」用于当前生成任务；读取全部字幕模式下不提供跨轨合并导出或整体偏移，避免跨轨重叠被错误合并。读取全部字幕只读，只有点击「保存并同步」才写入所选字幕的原轨。
- 字幕必须有合法、不重叠的起止时间，偏移后不能早于时间线起点。
- 模型、结果及任务日志在 `.vincisub/`，不纳入 Git。关闭程序后可按需清理旧的 `jobs/`（旧版文件模式可能留有音频）；保留 `models/` 避免重新下载。
- 任务在独立 Python 进程中执行；取消会结束进程并释放模型内存。关闭窗口前须先取消正在运行的任务。
- 出错时查看对应任务的 `.vincisub/jobs/<任务编号>/worker.log`；落轨问题另看 `placement.json` 和 `placement.log`。异常退出残留 `placement.lock` 时，先检查本次字幕轨再清理锁，避免重复写入。

## 参考脚本

点击「参考脚本…」，粘贴口播稿并勾选「生成字幕时参考脚本」，保存后再生成字幕。支持最多 6000 字，与词库同时使用；取消不保存，停用保留原稿。脚本保存在本机，跨时间线共用，更换素材时请更新或停用。

每次生成保存当时的脚本快照，通过 Qwen3-ASR 的上下文传入，辅助语境、专名和用词。实际口播的增删、改词和顺序变化以音频识别为准，不把脚本直接强制对齐或替换成字幕。提示不能保证模型完全遵循或准确率提升；建议只提供当前素材相关内容，长脚本会增加推理开销。

如果参考结果无法可靠对齐，该段会保留词库并按音频重新识别，完成后提示校对；不会为了套用脚本猜测时间戳。

## 一键优化

在字幕列表下方点击「一键优化…」，可组合勾选句尾逗号/句号清理、全部标点清理、短间隙填补。全部标点选项优先；句尾清理保留句中标点和闭合引号。仅含标点的字幕保留原文，避免生成空字幕。

间隙默认阈值为 0.5 秒，可在 0–10 秒调整。仅延长前句结束时间到下一句开始；超过阈值保留原停顿，末句不延长。处理本次生成列表；读取全部字幕时可选择一条字幕轨整轨处理，不跨轨填补。预览显示修改数量与前 8 条变化，点击「应用并同步」才写入；取消不修改。同步沿用旧内容冲突检查与失败恢复，单条样式仍可能随重建丢失。

### 重新对齐音频

在「一键优化」中勾选「重新对齐音频」，使用主面板选择的音轨（不选则跟随可听音轨），点击「计算音频对齐」。计算使用现有字幕文字和本地 ForcedAligner，不重新改写文字；音频从源片段读取到内存，不导出。计算完成先预览开始/结束时间，确认后「应用并同步」。

每条在原时间前后各 1 秒内搜索，句尾默认保留 0.15 秒（可调 0–1 秒），不越过下一条字幕。无效/零时长时间戳、冲突、无音频或超过 30 秒的单条保留原时间，并显示待校对序号。取消计算不写入时间线；大幅错位、文本与口播不符仍需人工校对，模型不提供可靠的语义置信度。对齐范围按字幕覆盖范围读取，不修改时间线入出点，单次仍限制 30 分钟。

### 生成后补填参考脚本优化

先在主面板「参考脚本…」中填写并保存，然后在优化窗口勾选「参考脚本优化」，点击「计算脚本优化」。优化窗口直接读取已保存的脚本，不再提供重复输入框；这里的勾选独立于“生成字幕时参考脚本”开关。使用本地 Qwen3-ASR 0.6B、现有词库和所选音轨重新识别，先预览文字变化，再应用到原轨。脚本仅为参考，可能修改之前校对过的文字，请核对预览。

只勾选脚本优化时保留原起止时间；同时勾选重新对齐则一起更新。改动脚本或对齐参数后需重新计算，不能应用旧预览；无可靠结果保留原条目。当前按已有字幕逐条读取音频，并限制在相邻字幕间隙中点，避免把相邻句子重复抄入；单独使用时不新增或删除字幕条目；组合「重新断句」可拆成多条。

### 检查更新

主面板右上角「检查更新」打开原生窗口，显示当前版本、检查结果和更新说明；发现新版后点击「查看新版」打开发布页。检查在后台执行，可关闭窗口或重试；不会自动下载或覆盖本机文件。

发布源为 [Chokamin/VinciSub](https://github.com/Chokamin/VinciSub)，配置位于 `update-source.json`。后续发布正式 Release 时，标签采用 `v1.2.3`，并同步更新 `pyproject.toml` 与 `vincisub/__init__.py` 版本号。检查使用 [GitHub 最新正式 Release API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)，不跟随普通 Git 提交或预发布版本。

### 自动整理字幕中间素材

每次生成、编辑或优化字幕成功同步后，插件自动清理当前项目媒体池里的 `placement-…` / `edit-…` 中间 SRT 素材，也会检查同项目以前成功任务积累的素材，无需点击清理按钮。

清理以本地任务路径和项目凭据确认归属，并检查项目内所有时间线的素材引用。用户导入的普通字幕、仍被引用的素材、失败或未完成任务的素材不会被清理；本地 SRT 和恢复记录保留。无法确认时跳过，诊断写入任务目录 `cleanup.json`。当前仅在 Resolve 21.1 启用。

### 标点优先断句与重新断句

首次识别默认优先在句号、问号、感叹号处断开；逗号和分号结合长度与时长判断，短引导语适当并入下一句。遇到字数或时长上限，优先退回可用标点处，再考虑词级边界；保留引号，不把小数点当作句号。

已有字幕在「一键优化」勾选「重新断句」，可设置每条字数。使用主面板音轨和本地对齐模型测量词级时间，先显示原条数与新条数、结果预览，再「应用并同步」到原字幕轨。先断句再清理标点，可以同时勾选去句尾标点或去全部标点。

单独重新断句保持原条目的整体起止范围和文字，按测得的词级时间拆分；不跨已有条目合并。没有标点时仍可按停顿和长度拆分，不自动编造标点。无法可靠对齐、单条搜索窗口超过 30 秒或拆分后不足一帧时保留原条目并提示校对。结合「重新对齐音频」才调整整体起止；结合参考脚本时可同时重新识别文字。

首次生成和重新断句还会保护常见中文词语，结合实际词间停顿整理无标点长句，并自动接平不超过 0.2 秒的小间隙；保留长停顿、短感叹句和末条结束时间。已有条目之间仍需勾选「填补短间隙」才会延长。断句采用本地词典，不额外下载识别模型；已有安装更新后请运行依赖安装脚本。参考观察、样本范围与限制见 [字幕节奏研究](docs/subtitle-rhythm-study.md)。
