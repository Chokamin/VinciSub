# 两频道扩展字幕研究（2026-09-12）

## 范围与方法

本轮新增 21 支公开影片：影视飓风 11 支、壹加壹 10 支，所附人工中文字幕共 17,583 条，影片总时长约 8.16 小时。加上上一轮四支，共 25 支、19,994 条字幕。这里的时长是样本影片长度，**不是逐秒观看或听校时长**。

完整统计所有新样本的 zh-CN / zh-TW 字幕文件，并对五个短片段抽查画面，其中三个片段用本地 ASR/对齐模型进行声学复测。不以自动转写替代人工字幕参考；访谈和英文挑战可能含翻译字幕，不能据其中文字数推导中文发声速度。会员内容及独立站宣传短片未纳入。部分公开视频持续缓冲，未能取得对应片段，不计为已观看。

统计口径沿用上一轮：有效字符为 Unicode 字母/数字（英文逐字母）；P90 为排序后 floor(N×0.9)；相接为相邻字幕间隔绝对值小于 2ms。它们描述字幕文件，不能证明音频无停顿。汇总数据见 [数据文件](expanded-subtitle-study-data.json)，完整字幕、媒体和模型输出仅存忽略目录 `.vincisub/research/expanded/`。

## 可复核观察

- 两个频道长度分布不同：影视飓风每片中位数为 6–11 字，壹加壹为 4–6 字。访谈、技术讲解和多人互动不能套用一个固定字数目标，因此保持用户可调上限。
- 911 条新样本含至少两个连续拉丁字母，53 条含数字之间的点、逗号、斜线、冒号或连字符。这些计数包含动态逐字展示的重复条目，不是独立语句数量。它们说明清理字符需要区分句子标点与技术数值，不能直接把数字中的符号全部删除。
- [Insta360 X6 上手 00:26–00:29](https://www.youtube.com/watch?v=AGCTmwYpfhI&t=26s) 的字幕轨保留传感器分数尺寸；[显示器对比 02:58–02:59](https://www.youtube.com/watch?v=7wxW3ETn_L4&t=178s) 的画面字幕保留小数。旧默认清理会改变其数值写法，本轮修正。
- [英文挑战 02:00–02:10](https://www.youtube.com/watch?v=4p23MYhiRPs&t=120s) 中可见对白、英文原句/中文翻译和大号人物信息。装饰标题、双语翻译都不作为本插件单轨中文 ASR 的自动模板。
- [山西 02:00–02:10](https://www.youtube.com/watch?v=3iBpUtRPfYs&t=120s) 与 X6 原始视频帧中，对白字幕不一定烧录在画面内；对白分析使用人工 CC 文件，画面里的大号标题与对白分开看。
- 美食搭配影片的 02:00–02:10 画面可见字幕文字，但该处没有对应 CC 条目；因此文件中的长空白不能简单视为真实静音，不据此扩大自动填补阈值。

## 这轮落到代码的改进

1. **默认去句子标点，保留数值含义。** 默认清理保留小数、分数、比例/时间、数字范围、百分数和常见技术标识内部符号；例如 `0.1` 不再变成 `01`。删除英文词间的分隔标点时补空格，避免拼成另一个词。手动“去掉全部标点”仍维持其明确的全部删除语义。
2. **数字及单位、启用词库里的专名一起断句。** 共享词边界保护用于首次生成和重新断句；不会把保护词写进全局分词词典，任务之间不相互污染。明显长停顿仍可打断，单个保护词允许超过字数上限。
3. **中英混排按显示宽度约束。** 中文按 1、ASCII 按 0.5 计入上限，保留英文词之间的空格。只是近似宽度，不是字体排版测量，也不是把所有字幕固定成短句。
4. **句中瞬时时间戳的有限恢复。** 三个真实片段初次生成均被原有零时长保护拒绝；在紧邻前词、间隔不超过 0.2 秒时允许归并并保留测得的瞬时端点。仍不对远距离缺失时间造时长，不使用比例对齐。

原有先标点断句、短间隙接平和长停顿保护继续使用。本轮没有修改模型权重、恢复省略字幕、添加翻译或识别说话人，也未改变字幕样式。

## 声学复测与限制

- 复测片段：山西 120–129.96 秒、X6 24–33.94 秒、显示器 174–183.93 秒；三段本地 Qwen 0.6B 识别后可完成新生成流程。
- 同一份显示器词级数据在修改前触发异常；修改后保留所有文字，能够输出字幕。这是异常恢复改善，不是识别准确率提升证据。
- 仍观察到人名和英文缩写识别错误，也有截断片段末尾不完整的句子。不要把模型输出当作参考字幕真值，专名仍需词库和人工校对。
- 图片抽查还包括英文挑战与美食搭配各约 10 秒；缓冲失败的赌场、汉斯·季默及音画同步影片没有完成画面抽查。其字幕文件仍纳入统计，并明确区分证据类型。
